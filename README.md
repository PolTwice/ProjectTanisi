# ProjectTanisi
2025-2026 CST Project Tanisi

Project Tanisi is an application that uses Indigenous teachings and story telling to teach Plains Cree to children age 4-7

# Features

Project Tanisi features 1 chapter based on the Seven Grandfather Teachings. This chapter has seven lessons. 
Each lesson features multiple modules that feature a story, and different learning modules to help teach Cree.
